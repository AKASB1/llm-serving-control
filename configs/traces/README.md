| File | Origin | License |

| `azure-code-600s.csv` (+ manifest) | excerpt of the Azure LLM inference trace 2023, coding service (`AzureLLMInferenceTrace_code.csv`), first 600 s | CC-BY 4.0 |

**Attribution.** The Azure excerpts are derived from the *Azure LLM inference trace 2023* published in [Azure/AzurePublicDataset](https://github.com/Azure/AzurePublicDataset) under the [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/), described in: Pratyush Patel, Esha Choukse, Chaojie Zhang, Aashaka Shah, Íñigo Goiri, Saeed Maleki, Ricardo Bianchini, "Splitwise: Efficient generative LLM inference using phase splitting", ISCA 2024.

The BurstGPT excerpt is derived from *BurstGPT* published in [HPMLL/BurstGPT](https://github.com/HPMLL/BurstGPT) under the [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/), described in: Yuxin Wang, Yuhan Chen, Zeyu Li, Xueze Kang, Yuchu Fang, Yeju Zhou, Yang Zheng, Zhenheng Tang, Xin He, Rui Guo, Xin Wang, Qiang Wang, Amelie Chi Zhou, Xiaowen Chu, "BurstGPT: A Real-World Workload Dataset to Optimize LLM Serving Systems", KDD 2025.

**Changes made to the Azure excerpts** (by `go run ./cmd/traceconv`, recorded in each manifest together with the SHA-256 of the source file): a time window was cut; timestamps were converted to seconds from the window start; `ContextTokens` and `GeneratedTokens` became `prompt_tokens` and `output_tokens`; every request was assigned the model name `chat-8b`; request IDs were added. No request was dropped or truncated in these excerpts.

**Changes made to the BurstGPT excerpt** (by `go run ./cmd/traceconv`, recorded in its manifest with the SHA-256 of the source file): the window was chosen by a rule that looks only at the trace (600-s windows starting at multiples of 600 s after the first request; the window with the most requests that have a non-zero response, the earliest on a tie); timestamps were converted to seconds from the window start; `Request tokens` and `Response tokens` became `prompt_tokens` and `output_tokens`; every request, `ChatGPT` or `GPT-4` in the source, was assigned the model name `chat-8b`; request IDs were added; the 18 rows of the window with zero response tokens (failed requests in the source) were dropped. No request was truncated.

Reproduce an excerpt from the downloaded source (kept out of git under `outputs/`):

```bash
go run ./cmd/traceconv -format azure -in outputs/real-traces/AzureLLMInferenceTrace_conv.csv -model chat-8b -start-s 0 -duration-s 300 -out configs/traces/azure-conv-300s.csv
go run ./cmd/traceconv -format burstgpt -in outputs/real-traces/BurstGPT_1.csv -model chat-8b -start-s 3063600 -duration-s 600 -out configs/traces/burstgpt-600s.csv
```
